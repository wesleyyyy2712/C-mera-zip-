# SwiftUI Camera 2026

Este repositório foi substituído pelo projeto enviado em `SwiftUICamera2026-AVFoundation-main.zip`. É um app iOS nativo em SwiftUI e AVFoundation com pré-visualização ao vivo, captura de fotos, gravação de vídeo, troca entre câmera frontal e traseira, flash e zoom por gesto.

O projeto foi ajustado para usar iOS 17 e Xcode 15, com Bundle ID `com.wesleyyyy2712.SwiftUICamera`. O workflow do GitHub Actions compila uma IPA não assinada e valida a estrutura `Payload/*.app`. Depois de baixada, a IPA precisa ser assinada pelo GBox com um certificado e Mobile Provision válidos.
